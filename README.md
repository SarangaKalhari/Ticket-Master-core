# 🎟️ Ticket Master Core

A Spring Boot backend application for an enterprise-style event ticket booking platform.
This system is designed to handle concurrent seat reservations, tier-based ticket pricing strategies, and audit logging to maintain reliable and scalable event booking operations.

The project follows a layered architecture and demonstrates best practices in building robust backend systems using Spring Boot and Spring Data JPA.

## 🚀 Features

- 🎫 Event ticket booking system

- 💺 Concurrent seat reservation handling

- 🔄 Full CRUD operations for event and ticket management

- 🧱 Layered architecture (Controller → Service → Repository)

- 🌐 RESTful API design

## 🛠️ Technologies Used

- Java

- Spring Boot

- Spring Data JPA

- Hibernate

- MySQL
- Maven

- REST API

- API testing

## 🧠 Key Concepts 

- Handling concurrent booking operations

- Implementing tier-based pricing strategies

- Building scalable REST APIs

- Using Spring Boot layered architecture

- Implementing audit logging for system monitoring
